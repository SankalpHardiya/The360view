# ✦ The 360 View

> A small experiment in creating a **3D image universe** using nothing but HTML, CSS & JavaScript.

Inspired by [Personaal Studio](https://personaal.studio/), I wanted to recreate that feeling of endlessly moving through a floating space of images.

### ✦ What’s happening?

- 🌀 Images distributed across a **3D sphere**
- 📐 Custom **3D & perspective mathematics**
- 🎯 Depth-based scaling, opacity & blur
- 🖱️ Scroll, mouse & drag interactions
- ⚡ Built with **vanilla JavaScript**
- 🤖 Developed with a little help from AI
